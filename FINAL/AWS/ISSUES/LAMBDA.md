# [Lambda issues](https://youtu.be/5ern5vYb1VE?si=DH4InZJjG1a9uENt)

1. Check the correct AWS event bridge trigger properly configured mapped to the lambda
2. Check the event based trigger configured with right JSON?
3. When there is a possibilities, check lambda code locally and confirm source code has any error.
4. Check the lambda cloud watch log groups for any error or info. \
   Monitor - > View logs in cloudwatch
5. Check the lambda configuration settings all are configure properly
6. Check whether Cloud Trail has been enabled for the region where lambda has been configured.
